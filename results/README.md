# Quiz results

Exported sessions, archived after the talk. Each file is the full state of one session:
every player, their score, how many they got right and how fast they answered.

```
results/
├── quiz-2026-09-16.json   ← exported from quiz/host.html
└── leaderboard.md         ← generated by .github/workflows/quiz-results.yml
```

Live results are **not** here — they live in MySQL and are served by `api/quiz.php`.
This folder is the archive.

## Archiving a session

1. Run the quiz. Everyone plays.
2. On the dashboard (`quiz/host.html`) hit **Export results (JSON)**.
3. Commit it:

```bash
mv ~/Downloads/quiz-2026-09-16.json results/
git add results/ && git commit -m "quiz: session results" && git push
```

4. `quiz-results.yml` runs, validates the question bank, builds `leaderboard.md`
   and commits it back. Watch it in the Actions tab.
